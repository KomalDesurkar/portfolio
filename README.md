## ✨ Features & Architecture

* **Modern Cinematic Interface:** Built with Lenis Smooth Scroll, GSAP 3 + ScrollTrigger, and HTML5 Canvas Node Graph.
* **Interactive Skills Constellation:** Dynamic particle physics network visualizing technical competencies (SQL, Power BI, Python, Jira, Postman, BPMN).
* **Interactive CLI Terminal:** Fully functional in-browser terminal supporting interactive commands (`resume`, `hire`, `skills`, `projects`, `experience`, `about`, `clear`).
* **Pinned Horizontal Exhibits:** Project case study showcase with 3D perspective tilt physics.
* **ATS-Optimized 1-Page PDF Resume:** Built with clean semantic structure, quantifiable metrics (Google XYZ formula), and standard ATS hierarchy.

## 💻 Running Locally

You can host and run the portfolio locally without installing external packages:

### Option 1 (Double-Click):
Double-click `start_server.bat` in Windows Explorer.

### Option 2 (PowerShell):
```powershell
powershell -ExecutionPolicy Bypass -File .\server.ps1
```
Open **[http://localhost:8000/](http://localhost:8000/)** in any browser.
